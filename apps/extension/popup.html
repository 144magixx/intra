连接此浏览器 Profile

将你授权的网站登录态提供给本机 Intra。请确认这是要使用的浏览器 Profile。此页面不显示或导出 Cookie。

选择允许同步的域

支持 DNS 域名和 localhost；此输入不支持 IP。不会自动推断父域：如需 .example.com 共享 Cookie，请明确填写 example.com。所选域包含 HTTP 与 HTTPS。

可选：扩大到所有网站

默认关闭。勾选后，点击下方按钮并批准 Chrome 权限，才允许为任意 HTTP/HTTPS URL 同步 Cookie。每次仍只读取指定 URL 的 Cookie，不导出整个浏览器存储。

每次同步按具体 URL 和存储筛选；可指定 Cookie 名称，省略时取适用于该 URL 的全部 Cookie。授权不会发现网络请求，也不保证已登录或业务调用成功。
